Cloud Services Assignment - Week 2

Explain what is serverless architecture?

Serverless architecture is a cloud computing model where the cloud provider manages the servers and infrastructure for you. The developer can focus on the application or functions instead of managing the servers.

When is it more feasible to use application containers (app virtualization) than full OS virtualization to provide networked services?

Containers are better when you want to run applications with fewer resources. They are lighter and faster than virtual machines.

Compare application containers to microservices.

Containers are used to package and run applications. Microservices are a way to divide an application into smaller services.

Describe shortly what is Kubernetes and what alternatives are there?

Kubernetes is a container orchestration system that manages containers. One alternative is Docker Swarm.
